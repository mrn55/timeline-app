# Timeline App
**Better name coming soon**  

## Purpose
The Timeline App allows you to input events that span date ranges (optional) and visualize them on a timeline. You can interact with the events by clicking on them to view overlapping event ages, giving you insights into relationships between various events over time.

## Features and Roadmap
- **Grouping and Linking:** Upcoming features will allow you to group related events and create links between them for better visualization and management.
- **Improved Editing:** Double-click on events to quickly edit them (this feature is still being refined for a smoother user experience).
- **Data Persistence:** All data must currently be manually saved. Future updates will include backend integration for syncing data.

## Setup and Running the App
1. Clone the repository to your local machine.
2. Inside the project folder, run:
   ```bash
   npm install
   ```
   This will install the required dependencies.

3. After the installation is complete, run the development server with:
   ```bash
   npm run dev
   ```
   This will launch the app locally.

## Example Data
I've included an `example_data.json` file for you to explore and quickly load events into the app. Feel free to modify the data and experiment with the timeline features.

## Future Plans
- **Backend Sync:** A future version will include backend support to sync your data across multiple devices.
- **Customizations:** There are plans for additional features such as custom event grouping, linking, styling, improved event filtering, and more interactive tools.
